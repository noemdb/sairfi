# Cierre del año, apertura del siguiente y recálculo

> Guía para el usuario: qué pasa después de aprobar un cálculo.
> Continúa a la guía “Cómo lograr el cálculo del ajuste”.

```
Cálculo aprobado → Cierre del año → Apertura del año siguiente
        ↕                                   ↕
  Reabrir si hay que corregir      Arrastrar saldos correctos
        ↕
  Corregir el índice → Volver a calcular
```

---

## 1. Cerrar el año

**Quién:** Contador o Asesor.

**Requisito:** tener al menos un cálculo aprobado y ningún cálculo pendiente o en borrador.

1. Pida el cierre del ejercicio.
2. El sistema valida que no queden cálculos sin aprobar. Si queda algo pendiente, no cierra y le dice qué falta.
3. Al cerrar, el año queda fijo y no se puede modificar. Solo se puede cambiar reabriéndolo (punto 3).

**Resultado:** año cerrado, listo para sustentar la declaración y para abrir el siguiente.

---

## 2. Abrir el año siguiente

**Quién:** Administrador o Contador.

1. Cree el nuevo ejercicio anual ligado al año anterior ya cerrado o aprobado.
2. Los saldos actualizados del cierre anterior pasan automáticamente como punto de partida del nuevo año, más los movimientos del nuevo período.
3. Recuerde: no puede tener dos años abiertos a la vez. El nuevo se crea como borrador y luego se abre para empezar a cargar datos.

**Resultado:** nuevo año abierto, con la base correcta heredada.

---

## 3. Reabrir un año ya cerrado

Si apareció un error, un documento tardío o se corrigió un índice:

**Quién:** solo el Asesor, indicando el motivo por escrito.

1. Solicite la reapertura con el motivo.
2. El año pasa a “reabierto” y permite corregir partidas, movimientos y volver a calcular.
3. Al volver a cerrar se genera una **nueva versión** del cálculo. La versión anterior se conserva para el historial: nada aprobado se borra.

---

## 4. Si se corrigió un índice de inflación

Un índice aprobado no se edita. Si tenía un error:

1. El responsable carga la corrección como una versión nueva, sin tocar la anterior.
2. El sistema avisa que hay cálculos que usaron el dato anterior.
3. Si el año está cerrado, primero se reabre; luego se vuelve a calcular y a aprobar. Los valores de las partidas solo se actualizan al aprobar el nuevo cálculo.

**Resultado:** historial limpio: cada cálculo explica con qué versión del índice se hizo.

---

## Qué le puede impedir avanzar (y cómo resolverlo)

- **Quiere cerrar con cálculos pendientes:** termine o anule esos cálculos primero.
- **Quiere abrir el siguiente sin haber cerrado el actual:** cierre o termine el actual primero.
- **El año anterior aún no está aprobado:** apruébelo antes de crear el anual.
- **Quiere corregir sin motivo:** la reapertura y la anulación siempre piden motivo escrito; queda en la bitácora.
